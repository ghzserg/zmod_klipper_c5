# Альтернативная калибровка VFA

`CALIBRATE_VFA T=0` по умолчанию использует альтернативный алгоритм на основе OpenCreator.
В консоли выводится название алгоритма, найденные частоты и выбранная частота для каждого двигателя.

Для сравнения можно вызвать прежний исправленный алгоритм напрямую:

```gcode
ZMOD_CALIBRATE_VFA T=0 ALTERNATIVE=0
SAVE_CONFIG
VFA_GRAPH MAX_SPEED=400
```

Для альтернативного алгоритма: `ZMOD_CALIBRATE_VFA T=0 ALTERNATIVE=1`, затем `SAVE_CONFIG`.
Для постоянного выбора прежнего алгоритма добавьте `alternative: False` в существующую секцию
`[stepper_resonance_tester]`. По умолчанию `alternative: True`.

Поиск частоты: диапазон 20–300 мм/с (ограничен max_velocity), геометрический шаг до 8%,
уточнение до трёх пиков, калибровка до двух выраженных резонансов.
Кандидаты проверяются на достижимость скорости и достаточную длину равномерного участка для всех гармоник.
Если выраженного допустимого пика нет, используется настроенная частота (обычно 200 Гц).
Общая амплитуда минимизирует сумму квадратов остатков по параболам двух направлений.
Результат проверяется на обоих направлениях; требуется снижение суммарной RMS-амплитуды
не менее 5%. При нескольких частотах сравнивается сумма квадратов остатков на одинаковых
скоростях и гармониках. Измерительное окно, FFT, координаты, ускорение Z-Mod и VFA_GRAPH
не изменены. Частота сохраняется только в диагностическом файле, компенсация — через SAVE_CONFIG.

Источник алгоритма: https://github.com/FlashForge-C5-Modding-Group/kalico/blob/7da732e09d4e213b7766482b6cfdf7e75ee9e191/klippy/extras/stepper_resonance_tester.py
