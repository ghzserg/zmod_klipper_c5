# Диагностика VFA на Creator 5 / Creator 5 Pro

Команда `VFA_GRAPH` сравнивает вибрации без компенсации и с сохранённой
компенсацией VFA. Алгоритм калибровки и прошивка MCU не изменяются.

Перед запуском освободите стол. Команда сама выполняет штатную подготовку
через `_T_IN`, выбирает инструмент `T` (0–3, по умолчанию 0),
опускает стол до Z не менее 100 мм и возвращает инструмент через `_T_OUT NO_Z=0`.
Печать и пауза блокируют запуск теста.
Если сохранённая компенсация отсутствует, измеряется только исходный уровень вибраций.

```gcode
VFA_GRAPH
VFA_GRAPH T=2 AXIS=X MIN_SPEED=20 MAX_SPEED=150 STEP=10 REPEAT=1
```

По умолчанию измеряются оба двигателя, в обоих направлениях, от 20 до
300 мм/с с шагом 10 мм/с (не выше текущего лимита скорости).
На каждой скорости и в каждом направлении чередуются измерения OFF/ON.
По умолчанию выполняются три пары (`REPEAT=3`), на графике — медиана
валидных пар. Для быстрой проверки используйте `REPEAT=1`.
Параметр AXIS обозначает двигатель,
а не направление движения каретки.

В папке `mod_data/vfa/vfa_T*_*` находятся CSV и PNG. Пробелы на графиках
означают недостаточную длительность равномерного движения (0,25 с и 20
периодов гармоники), потерю отсчётов или частоту выше 400 Гц. Траектория
не удлиняется автоматически. CSV хранит каждый повтор, частоту гармоники,
длительность и частоту дискретизации, продольное, поперечное и суммарное
ускорение. В `metadata.json` — параметры компенсации в единицах MCU
и условия измерений.
PNG показывают ускорение и оценку амплитуды смещения датчика в мкм
по формуле A/(2πf)². Это не прямое измерение смещения сопла или качества
поверхности детали. Сравнивайте один инструмент, направление и гармонику.

Тест не сохраняет конфигурацию и восстанавливает действовавшие до запуска
параметры компенсации и ограничения движения. Input Shaper не изменяется:
измеряется участок равномерного движения. При аварийном отключении MCU
восстановление возможно только при перезапуске и чтении сохранённой конфигурации.

Для генерации PNG используется отдельный процесс Python 3 с Matplotlib
в chroot Z-Mod через существующий `.shell/chroot.sh`, как у графиков
шейперов. В chroot CSV и PNG доступны через `/opt/config/mod_data/vfa/`.
