# VFA diagnostics for Creator 5 / Creator 5 Pro

[Русская версия](#диагностика-vfa-на-creator-5--creator-5-pro)

The `VFA_GRAPH` command compares vibrations with VFA compensation disabled
and with the saved compensation settings. It does not change the calibration
algorithm or MCU firmware.

Clear the build plate before starting. The command performs the standard
preparation using `_T_IN`, selects tool `T` (0–3, default 0), lowers the bed
to at least Z=100 mm, and returns the tool using `_T_OUT NO_Z=0`.
The test cannot run while printing or paused.
If no compensation settings are saved, only baseline vibrations are measured.

```gcode
VFA_GRAPH
VFA_GRAPH T=2 AXIS=X MIN_SPEED=20 MAX_SPEED=150 STEP=10 REPEAT=1
```

By default, both motors are tested in both directions, from 20 to 400 mm/s
in steps of 10 mm/s, without exceeding the current velocity limit.
The toolhead moves along 45° diagonals within the intersection of the
0–255 mm area, kinematic limits and VFA range, with a 10 mm margin.
The default `ADAPTIVE=1` adjusts the path length to provide 0.6 seconds
of usable measurement time and at least 20 cycles of TD1, if the available
diagonal allows it. All paths share the same center.
Use `ADAPTIVE=0` for full-length diagonals.
Acceleration is limited to 5000 mm/s², the configured VFA acceleration
and the current acceleration limit.
At each speed, both forward and reverse passes are measured without an
idle return move before switching the compensation mode (OFF/ON).
The order of the modes alternates. The toolhead stops fully and pauses
between passes.
The default is one measurement (`REPEAT=1`) per direction and mode.
Use `REPEAT=3` for a more reliable comparison: graphs show the median
of matched valid measurements.
The AXIS parameter selects the motor, not the direction of toolhead motion.

CSV and PNG files are saved in `mod_data/vfa/YYYYMMDD_HHMM`.
If another test starts in the same minute, a suffix such as `_01` or `_02`
is appended. The directory name uses the printer's local date and time.
Graph labels are in Russian when Z-Mod is set to Russian, otherwise in
English. The tool number is shown in the PNG files and `metadata.json`.

The console reports the start of measurements, the start and completion
of graph generation, the output location (Configuration → mod_data/vfa/…),
and a brief comparison of median transverse sensor displacement amplitudes
up to 400 Hz for each motor.
Only matched valid OFF/ON points are compared. If compensation is unavailable,
the baseline value is reported. The summary is saved in `summary.json`.

The console lists speeds with a notable increase in transverse displacement
for each harmonic. Crosses on the displacement graph mark those points.
Only matched valid points up to 400 Hz with an increase of at least 20%
and 0.05 µm are flagged. These are heuristic thresholds, not sensor accuracy.
The details are saved in `summary.json`.

Gaps in the graphs indicate insufficient constant-speed measurement time
(at least 0.25 seconds and 20 cycles of the harmonic), missing samples,
or frequencies exceeding 720 Hz or 45% of the actual sampling rate.
Orange shading marks frequencies above 400 Hz, where the sensor filter
may attenuate amplitudes. Compare ON and OFF at the same frequency rather
than relying on absolute amplitudes.

The CSV files contain each repeat, harmonic frequency, validity indicator,
measurement duration, sampling rate, and longitudinal, transverse and total
acceleration. The `metadata.json` file records compensation settings in MCU
units and measurement conditions.
The PNG files show acceleration and estimated sensor displacement amplitude
in µm, calculated as A/(2πf)². This is not a direct measurement of nozzle
displacement or print surface quality. Compare the same tool, direction
and harmonic.

The test does not save configuration changes and restores the compensation
settings and motion limits that were active before the test.
Input Shaper is unchanged: only constant-speed motion is analyzed.
If the MCU shuts down, settings can only be restored after restarting
and loading the saved configuration.

PNG files are generated by a separate Python 3 process with Matplotlib
inside the Z-Mod chroot, using the existing `.shell/chroot.sh`, as with
Input Shaper graphs. Inside the chroot, CSV and PNG files are available
under `/opt/config/mod_data/vfa/`.

# Диагностика VFA на Creator 5 / Creator 5 Pro

Команда `VFA_GRAPH` сравнивает вибрации без компенсации и с сохранённой
компенсацией VFA. Алгоритм калибровки и прошивка MCU не изменяются.

Перед запуском освободите стол. Команда сама выполняет штатную подготовку
через `_T_IN`, выбирает инструмент `T` (0–3, по умолчанию 0),
опускает стол до Z не менее 100 мм и возвращает инструмент через `_T_OUT NO_Z=0`.
Печать и пауза блокируют запуск теста.
Если сохранённая компенсация отсутствует, измеряется только исходный уровень вибраций.

```gcode
VFA_GRAPH
VFA_GRAPH T=2 AXIS=X MIN_SPEED=20 MAX_SPEED=150 STEP=10 REPEAT=1
```

По умолчанию измеряются оба двигателя, в обоих направлениях, от 20 до
400 мм/с с шагом 10 мм/с (не выше текущего лимита скорости).
Движение по диагоналям 45° в пределах области 0–255 мм,
границ кинематики и диапазона VFA, с отступом 10 мм от их пересечения.
По умолчанию `ADAPTIVE=1`: длина рассчитывается для 0,6 с полезного
измерения и не менее 20 периодов TD1, если позволяет доступная диагональ.
Центр траектории одинаков на всех скоростях. `ADAPTIVE=0` — полные диагонали.
Ускорение не выше 5000 мм/с², настройки VFA и текущего лимита.
На каждой скорости измеряются прямой и обратный проходы без холостого
возврата, затем меняется режим компенсации OFF/ON. Порядок режимов
чередуется. Между проходами сохраняются полная остановка и паузы.
По умолчанию один повтор (`REPEAT=1`) для каждого направления и режима.
Для более точного сравнения используйте `REPEAT=3`: на графике — медиана
валидных пар.
Параметр AXIS обозначает двигатель,
а не направление движения каретки.

В папке `mod_data/vfa/ГГГГММДД_ЧЧММ` находятся CSV и PNG.
При повторном запуске в ту же минуту добавляется суффикс `_01`, `_02` и т. д.
Дата и время локальные для принтера. Подписи на графиках русские при
русском языке Z-Mod, иначе английские. Номер инструмента указан в PNG
и `metadata.json`.
В консоли отображаются начало измерений, начало и окончание расчёта графиков,
путь к результатам (Конфигурация → mod_data/vfa/…) и краткое сравнение
медиан амплитуды поперечного смещения датчика до 400 Гц для каждого двигателя.
Сравниваются только совпадающие валидные точки OFF/ON; при отсутствии
компенсации выводится исходное значение. Сводка сохраняется в `summary.json`.

В консоли выводятся скорости заметного роста поперечного смещения по гармоникам.
Крестики на графике смещения отмечают эти точки. Учитываются только
сопоставимые достоверные точки до 400 Гц с ростом не менее 20% и 0,05 мкм.
Это пороги отбора, а не погрешность датчика. Подробности в `summary.json`.

Пробелы на графиках
означают недостаточную длительность равномерного движения (0,25 с и 20
периодов гармоники), потерю отсчётов или частоту выше 720 Гц (также
не выше 45% фактической частоты дискретизации). Оранжевая область на
графиках — частоты выше 400 Гц: амплитуды могут быть занижены фильтром
датчика. Сравнивайте ON/OFF на одной частоте, не абсолютные амплитуды.
CSV хранит каждый повтор, частоту гармоники, признак достоверности,
длительность и частоту дискретизации, продольное, поперечное и суммарное
ускорение. В `metadata.json` — параметры компенсации в единицах MCU
и условия измерений.
PNG показывают ускорение и оценку амплитуды смещения датчика в мкм
по формуле A/(2πf)². Это не прямое измерение смещения сопла или качества
поверхности детали. Сравнивайте один инструмент, направление и гармонику.

Тест не сохраняет конфигурацию и восстанавливает действовавшие до запуска
параметры компенсации и ограничения движения. Input Shaper не изменяется:
измеряется участок равномерного движения. При аварийном отключении MCU
восстановление возможно только при перезапуске и чтении сохранённой конфигурации.

Для генерации PNG используется отдельный процесс Python 3 с Matplotlib
в chroot Z-Mod через существующий `.shell/chroot.sh`, как у графиков
шейперов. В chroot CSV и PNG доступны через `/opt/config/mod_data/vfa/`.
